# OIBSIP — Data Science Internship 🚀

## 📌 About This Repository

This repository contains the projects completed during my **Data Science Internship at Oasis Infobyte (OIBSIP)**.

The internship provided hands-on experience in Python, Data Analysis, Machine Learning, Natural Language Processing, data visualization, and model evaluation.

Each task focuses on solving a practical problem using real-world datasets and machine learning techniques.

---

# 📚 Projects Completed

## Task 4 — Email Spam Detection using NLP 📧

### Objective

Build a binary classification model that identifies whether a message is **Spam** or **Ham**.


### NLP Techniques

- Text cleaning
- Lowercase normalization
- TF-IDF Vectorization
- Text feature extraction

### Models Used

- Logistic Regression
- Multinomial Naive Bayes

### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

### Best Performing Model

Logistic Regression achieved the strongest overall performance on the test data.

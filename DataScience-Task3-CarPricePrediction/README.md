# 🚗 Car Price Prediction with Machine Learning

## 📌 Project Overview

This project predicts the selling price of used cars using machine learning techniques. The dataset was cleaned, analyzed, and processed, and multiple regression models were trained to estimate car prices based on vehicle-related features.

---

## 🎯 Objectives

- Clean and preprocess car price data
- Handle missing values and duplicates
- Perform feature engineering
- Conduct exploratory data analysis (EDA)
- Encode categorical variables
- Train and compare regression models
- Evaluate model performance using MAE, RMSE, and R² score

---

## 📂 Dataset

The project uses the **CarDekho used car dataset**, which contains information such as:

- Car Name
- Year
- Present Price
- Selling Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Owner

## 🤖 Models Used

### 1. Linear Regression
A simple baseline regression model.

### 2. Random Forest Regressor
An ensemble learning model that combines multiple decision trees for improved prediction accuracy.

---

## 📊 Evaluation Metrics

The models were evaluated using:

- **MAE (Mean Absolute Error)**
- **RMSE (Root Mean Squared Error)**
- **R² Score**

---

---

## 🏆 Result

The **Random Forest Regressor** achieved better performance than Linear Regression with lower prediction error and a higher R² score, making it the preferred model for car price prediction.

---

## 📌 Conclusion

This project demonstrates an end-to-end machine learning workflow for predicting used car prices. It highlights the importance of data cleaning, feature engineering, exploratory analysis, model comparison, and evaluation in building effective predictive models.

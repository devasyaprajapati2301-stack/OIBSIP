# 🌸 Iris Flower Classification using Machine Learning

## 📌 Project Overview

This project classifies Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

using Machine Learning classification algorithms.

The project demonstrates the complete Machine Learning workflow, including data preprocessing, exploratory data analysis (EDA), model building, evaluation, and comparison.

---

## 📊 Dataset

- Iris Dataset
- Source: Scikit-Learn (`load_iris()`)

Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target:
- Setosa
- Versicolor
- Virginica

---

## 🔍 Exploratory Data Analysis

The following visualizations were performed:

- Count Plot
- Histogram
- Box Plot
- Pair Plot
- Correlation Heatmap

---

## 🤖 Machine Learning Models

- Logistic Regression
- Decision Tree Classifier

---

## 📈 Model Performance

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 96.67% |
| Decision Tree | 93.33% |

### ✅ Best Model

Logistic Regression achieved the highest accuracy and was selected as the final model.

The project successfully classified Iris flower species using Machine Learning. Logistic Regression outperformed Decision Tree with an accuracy of 96.67%, making it the best-performing model for this dataset.

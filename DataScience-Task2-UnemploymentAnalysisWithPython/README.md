# 📊 Unemployment Analysis with Python

## 📌 Project Overview

This project analyzes unemployment trends in India using Python and Exploratory Data Analysis (EDA). The dataset was cleaned, analyzed, and visualized to identify patterns across regions, urban and rural areas, and different time periods.

---

## 🎯 Objectives

- Load and clean the unemployment dataset
- Handle missing values
- Perform Exploratory Data Analysis (EDA)
- Analyze unemployment trends by region and month
- Compare unemployment before and after COVID-19
- Visualize insights using various charts

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📈 Visualizations

- Distribution of Unemployment Rate
- Urban vs Rural Comparison
- Region-wise Average Unemployment
- Top 10 States with Highest Unemployment
- Monthly Unemployment Trend
- Time-Series Analysis for Selected States
- Correlation Heatmap
- Pre-COVID vs Post-COVID Comparison

---

## 📌 Conclusion

The analysis revealed that unemployment rates varied across different regions and increased significantly during the COVID-19 period. The project demonstrates how Python can be used to clean, analyze, and visualize real-world datasets to generate meaningful insights.
